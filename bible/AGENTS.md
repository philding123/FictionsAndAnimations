# AGENTS.md — bible/ · 视觉风格圣经

## 1. 职责与定位

- 定义全项目视觉的唯一标准：风格定义、光影、色彩体系、镜头语言。
- 下游：`characters/`（角色设计遵循）、`episodes/*/assets.md`（场景与关键帧遵循）、质检对照。

## 2. 结构与组件

| 文件 | 说明 |
|------|------|
| `style-guide.md` | 美漫厚涂风格总纲（基调/光影/色彩/构图/质感技术定义） |

（后续可增：`color-script/` 每集色彩脚本、`scenes/` 场景设定集）

## 3. 铁律与不变式

- `style-guide.md` 是视觉争议的**最终裁判**；与个人偏好冲突时以它为准。
- 变更本目录 = 全项目视觉标准变更：须在 `docs/` 留决策记录，并同步 PROJECT_SPEC §3。
- 任何"参考《双城之战》"的解释都落到本目录条文，不允许各集自行发挥定义。

## 4. 校验

- 每集质检 checklist 第 3 项（风格）逐条对照 `style-guide.md` 的可判条目。
