# 风格圣经 — 美漫厚涂（Style Guide）

> 视觉争议的最终裁判。所有角色设计（`characters/`）、场景设定与关键帧（`episodes/*/assets.md`）、
> 成片质检（qa.md 第 3 项）都对照本文件。变更本文件 = 变更全项目视觉标准。

## 1. 风格定义

**美漫厚涂（Painterly / Impasto）**，参考《双城之战》（Arcane）：

- 写实人体比例与结构，手绘感的笔触暴露在外——边缘允许"没画完"的松动感。
- 大色块概括 + 关键处细分（脸部、手部精画，衣服远端概括）。
- 质感靠笔触与边缘控制表达：金属利硬、皮毛松散、丝绸流动、石头方硬。
- **禁止**：日漫赛璐璐平涂（均匀色块+硬阴影线）、纯写实照片感、低幼 Q 版。

## 2. 人物造型规则

| 项 | 规则 |
|----|------|
| 头身比 | 成人 7.5–8 头身（写实）；儿童按年龄 5–6 头身；提利昂按侏儒症写实比例 |
| 面部 | 结构化写实：明确的眉弓/鼻梁/颧骨；避免网红脸模板，角色之间辨识度优先 |
| 线条 | 无外轮廓勾线；用色块明暗交界替代线稿（Arcane 特征） |
| 比例 | 五官位置遵循写实三庭五眼；表情幅度可比真人夸张约 20% |
| 材质 | 服装必须写明材质（呢料/皮革/锁甲/丝绸），材质决定笔触方式 |

## 3. 光影

- 强方向性戏剧光，每场戏必须有**光源设定**（火把/夕阳/月光/阴天漫射）。
- 明暗对比 ≥ 4:1 的场景占每集 ≥ 40%（戏剧性底线）。
- 暗部保留 15%–25% 细节信息，不死黑；亮部不过曝成纯白。
- 常用光效：室内火光（暖橙 + 深蓝环境反射）、北境雪天（冷青灰漫射 + 呼出白气）、
  篝火/龙焰（底部暖橙渐变到暗红）。

## 4. 色彩体系（三条叙事线的色彩脚本基线）

| 叙事线 | 主色 | 辅色 | 光倾向 |
|--------|------|------|--------|
| 北境 / 史塔克 | 青灰 `#5B6770`、铁蓝 `#37424E`、雪白 `#E8ECEF` | 灰褐 `#8A7968` | 冷漫射、低饱和 |
| 兰尼斯特 / 都城 | 帝金 `#C9A227`、绯红 `#8E1F2F`、象牙 `#F2EAD3` | 深棕 `#4A3625` | 暖金侧光、高饱和 |
| 坦格利安 / 多斯拉克 | 大地棕 `#7A5230`、铜金 `#B07D3F`、龙焰橙 `#E06A1B` | 血红 `#7C1E1E` | 硬顶光、荒漠暖调 |
| 守夜人 / 长夜 | 玄黑 `#1E2226`、雾灰 `#6E7B84`、冰蓝 `#9FC4D0` | — | 月光冷调、极低饱和 |

- 每集分镜阶段产出色彩脚本（3–5 个关键帧色条），标注场景光源。
- 家族场景色不得互换（绝不在红色兰尼斯特光里拍史塔克家宴）。

## 5. 镜头语言

- 电影级构图：多用手持感微晃（情绪场）、低角度仰拍（权力/威严）、
  过肩与框中框（阴谋/监视）、大远景留白（苍凉感）。
- 平均镜头长 6–9 秒；对白场景正反打 ≤ 4 秒/镜；每集至少 2 个长镜头呼吸（≥12s）。节奏原则：**一集只讲一条主线**，宁慢勿赶。
- 转场以硬切为主；时间跳跃用黑场 + 旁白或地图推进镜头。

## 6. 厚涂质感的技术落地（AI 生成关键帧时的 prompt 基底）

```text
【风格基底词】thick painterly brush strokes, impasto, visible texture,
dramatic directional lighting, cinematic composition, dark fantasy,
Arcane-style stylization, realistic proportions, no outline lines,
muted desaturated palette with strong accent colors, 35mm film grain
【负面词】anime cel shading, flat colors, chibi, photorealistic photo,
3d render plastic look, watermark, text
```

- 关键帧生成分辨率 ≥ 1920×1080；角色特写必须附该角色 roster.json 的 palette hex。
- 同一场景的多张关键帧必须锁定同一光源描述，避免跨镜头跳光。
