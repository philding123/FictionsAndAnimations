# 异鬼（white-walker）作为特效角色注册 roster 并走完整定稿流程

- Date: 2026-10-10
- Status: accepted
- Owners: 未记录
- Related issues:
- Related daily notes: [2026-10-10](../daily/2026-10-10.md)

## Decision

- 异鬼作为"特效角色"在 `characters/roster.json` 正式注册，与普通角色一样走完整定稿流程（design.md + sheet.svg + 视觉验收）。

## Context

- S01E01 序幕需要异鬼上屏；评审发现其未注册，属于角色门禁缺口（评审整改项之一）。

## Options Considered

- 作为特效/生物豁免 roster 流程 —— 被否：一致性规则无例外。

## Rationale

- R4 无例外；怪物也必须有可追溯的调色板与特征清单，否则序幕关键帧的角色一致性无从校验。

## Consequences

- Positive: 序幕全部画面元素可追溯到 roster；特效角色有了先例。
- Negative: 特效角色的 SVG 规范图表达力有限，需在关键帧阶段补质感。
- Follow-up: 后续非人角色（如龙）沿用此模式。

## Verification

- white-walker 定稿并过视觉验收（roster v1，2026-10-10）。
