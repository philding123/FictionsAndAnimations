# AGENTS.md — source/ · 小说源文本（只读输入）

## 1. 职责与定位

- 存放《冰与火之歌》提取后的源文本与章节索引，是**全项目唯一剧情事实源**。
- 上游：根目录 `.mobi`；下游：`episodes/*/plan.md`（选材）与 `script.md`（引用对白）。

## 2. 结构与组件

| 文件 | 说明 |
|------|------|
| `raw/全书_raw.html` | MOBI 解出的原始标记文本（中间产物，勿引用） |
| `raw/全书_clean.txt` | 清洗后的纯文本（分页符保留，分册脚本的输入） |
| `text/卷NN_书名_X.txt` | **15 个分册**正文，章节以 `=====第NNN章 POV: 名=====` 分隔 |
| `chapters_index.json` | 365 章元数据：seq/book/part/chapter/pov/chars，**定位章节一律先查这里**（跋/附录/家谱等非正文块已过滤） |

## 3. 铁律与不变式

- 🚫 **只读**：本目录所有文件禁止修改、删除、"顺手修错字"（R6）。
- 单册 18–26 万字，**禁止整读**：用 `chapters_index.json` 定位 → 按章节标记切片读取。
- 引用格式：`卷07_冰雨的风暴_上 §12`（文件名 + 章序号）。

## 4. 操作

- 重建命令（仅当文件缺失/损坏）：根 `AGENTS.md` §6 三条命令按序执行。
- 校验：分册数必须为 15、章节总数必须为 365（纯正文，卷一为 27/26/20 章），
  否则 split_books.py 会报错或过滤失灵。
